# Decision records

One numbered file each: `0001-short-title.md`. Status is `proposed`, then
`accepted`. A changed mind is a new record that supersedes the old one — an
accepted record is never edited.

Template (Fowler; see also adr.github.io):

```
# NNNN. Title

Status: proposed | accepted | superseded by NNNN

## Context
## Decision
## Consequences
```
